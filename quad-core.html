Quad-Core

Four independent validation paths. One evaluation packet. Fail-closed consensus. Dual-Core is archived. Dual-Validation remains Core 1 inside the four.

Why four

A single inspector can be locally consistent and still miss a class of failure. A probabilistic ensemble of four models can agree and still be wrong together. Quad-Core uses rule diversity, not sampled confidence. Identical packet, identical prior state, identical votes on every replay.

The four cores

Core 0 · Identity Shield

Who is speaking

Emmy Clause on identity and configuration. Drift, spoof, and unauthorized rewrite fail closed. If the system is no longer itself, it does not get to act.

Core 1 · Dual-Validation

Is the jump legal

Sealed ladder and Hazard Taxonomy. A Class-1 anomaly cannot authorize LOCKED. A Class-5 event cannot be parked in BASELINE.

Core 2 · Loop-Closure

Did the cycle finish

READ → INTERPRET → DECIDE → VALIDATE → ACT → LOG. Stall, abort, and partial act are REJECT.

Core 3 · Boundary Sentinel

Is this the right room

Domain, schema, baseline map. Hospital packets do not become vehicle packets by renaming fields.

What Quad-Core is not

Not an ensemble

No sampled votes. No temperature. No learned weights between cores.

Not Dual-Core renamed

Dual-Validation is Core 1. The other three vetoes are new paths.

Not a network service

The core loop has no external calls. Replay does not need a live model.

Not a certified device

v1.0.0 is the Guardian spine. Hospital and flight clearance are separate gates.

Reference contract

Pure-Python, zero-dependency reference. Identical inputs → identical four votes → identical Master Log chain. Amy stays dormant until isolate, paradox, or Class-5 containment.
